# /review

对最近改动做穷尽式 review：

1. `git diff HEAD~1`（或指定范围）通读
2. 按严重度排序输出问题：P0（漏洞/泄露）→ P1 → P2 → P3
3. 安全面强制复查 `.agents/rules/security.md`：
   - 密钥零化 / 记忆加密覆盖保护
   - 审计日志无敏感字段
   - 特性门控未被绕过
   - 输入验证在信任边界
4. 发布前 review 附加 F-01~F-14 全项
5. 结论必须带验证证据（测试通过数、clippy 结果），不空口断言
