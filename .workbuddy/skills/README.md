# .workbuddy/skills/ — 开发辅助技能

> 与顶层 `skills/`（ganyu **运行时**技能库，nomifun 36 skills）严格区分：
> - **顶层 `skills/`**：ganyu agent 执行任务时加载的技能（产品能力）。**勿在此添加开发辅助内容。**
> - **本目录**：编码 agent（WorkBuddy/Claude Code 等）开发 ganyu 时的辅助技能。

## 使用约定

1. 开发辅助技能放本目录，每个技能一个子目录 + `SKILL.md`
2. 技能内容须与 `.workbuddy/rules/` 一致，不引入冲突约定
3. 通用技能（跨项目复用）优先放用户级 `~/.workbuddy/skills/`，不塞进本仓库
